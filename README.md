# health-diet-warning

健康饮食主题的多页静态网站原型，包含饮食主题展示、成本计算器和厨房行动清单。

## 运行

下载或克隆仓库，用浏览器打开 [`index.html`](index.html)，再通过页面导航访问计算器和行动清单。页面无需安装依赖或构建，样式、图表、动画和字体通过网络加载。

## 页面与文件

| 文件 | 用途 |
| --- | --- |
| [`index.html`](index.html) | 主题介绍和图表展示 |
| [`calculator.html`](calculator.html) | 饮食与成本情景演示 |
| [`action.html`](action.html) | 可勾选的厨房行动清单 |
| [`main.js`](main.js) | 主页交互脚本 |
| [`resources/`](resources/) | 网站图片 |

项目规划见[大纲](outline.md)，页面设计见[视觉设计](design.md)和[交互设计](interaction.md)。
